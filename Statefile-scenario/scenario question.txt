Q.29.
What happens when the state file and actual infrastructure are out of sync?

       when the state file and actual infra isnt sync or mismatch it is said to be drift state and when we run terraform plan it will show plan to add or destroy depending if the resource is missing in the terraform statefile, terraform refresh helps in syncing the statefile with cloud.
